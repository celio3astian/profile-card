# Cartão de Perfil com Efeito Tilt

Projeto de uma página pessoal simples e responsiva, desenvolvida com **HTML, CSS e JavaScript**, contendo um cartão de perfil com efeito 3D de inclinação utilizando a biblioteca **VanillaTilt.js**.

## 🚀 Sobre o projeto

O objetivo deste projeto é criar um cartão de apresentação pessoal com um visual moderno e interativo.

Ao movimentar o mouse sobre o cartão, é aplicado um efeito de inclinação 3D, tornando a experiência mais dinâmica.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* VanillaTilt.js

## 📁 Estrutura do projeto

```text
profile-card/
├── images/
├── index.html
├── style.css
├── script.js
└── README.md
```

### Principais arquivos

* `index.html` — estrutura principal da página.
* `style.css` — responsável pela estilização e layout.
* `script.js` — configura os efeitos e funcionalidades em JavaScript.
* `images/` — contém as imagens utilizadas no projeto.

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse a pasta do projeto:

```bash
cd profile-card
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar uma extensão como **Live Server** no Visual Studio Code.

## ✨ Funcionalidades

* Cartão de perfil pessoal.
* Efeito de inclinação 3D com VanillaTilt.
* Links para redes sociais.
* Layout simples e moderno.
* Estrutura leve, sem necessidade de frameworks.
* Pronto para publicação no GitHub Pages.

## 📚 VanillaTilt

A biblioteca **VanillaTilt.js** é utilizada para criar o efeito de movimento 3D do cartão.

Neste projeto, ela é carregada dinamicamente pelo arquivo `script.js` quando necessário.
